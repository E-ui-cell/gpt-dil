# Tampermonkey

Open a raw script URL to install it in Tampermonkey.

- [model-pin.user.js](https://raw.githubusercontent.com/E-ui-cell/gpt-dil/main/userscripts/model-pin.user.js) — experimental model selection, effort setting, optional reason hint, and server-resolved model display. See [model-pin documentation](../docs/model-pin.md).
- [plain-text-payload.user.js](https://raw.githubusercontent.com/E-ui-cell/gpt-dil/main/userscripts/plain-text-payload.user.js) — appends an editable plain-text preference to the latest user message.

The model-pin script edits only matching ChatGPT conversation POSTs. Its custom model and effort fields are experimental and must be checked against the server's response.
